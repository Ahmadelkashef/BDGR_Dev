Android resources copied by CI into `android/app/src/main/res/` (the workflow regenerates `android/` every build).

- `values/bdgr_colors.xml`: notification accent color (BDGR red).
- `raw/bdgr_keep.xml`: stops release shrinking from removing them (they're used by name only).
